# Sumber materi

`course.json` adalah sumber tunggal isi portal. `references.json` memuat bibliografi, tautan resmi dan batas penggunaan. HTML dihasilkan dengan `python3 scripts/build.py`. Edit sumber, bukan halaman hasil.

Materi adalah kompilasi baru berdasarkan kerangka yang disepakati, bukan reproduksi naskah kuliah lama yang belum tersedia. Nomor pertemuan mengikuti peta 16 slot: 14 materi, UTS pada 8, UAS pada 16. Pemetaan pemadatan 13 kali tatap muka disediakan terpisah dan tidak mengubah identitas unit.
