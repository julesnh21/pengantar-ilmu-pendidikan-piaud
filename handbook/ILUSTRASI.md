# Ilustrasi dan panduan visual · edisi 1.1

14 ilustrasi kasus dibuat dengan **image generation bawaan**; tidak menggunakan CLI. Adegan rekaan berbantuan AI, bukan dokumentasi anak atau bukti penelitian. Semua aset web tersimpan di `assets/scenes/`, disalin saat build ke `docs/assets/scenes/`. Diagram SVG dibuat dengan kode agar label dan hubungan dapat diperiksa.

## Pola belajar

Amati adegan → pisahkan deskripsi dan interpretasi → baca konsep dan sumber → bandingkan tindakan → coba penalaran → tinjau pembahasan. `content/visuals.json` menyimpan teks alternatif, pertanyaan, pembahasan, dan spesifikasi diagram. Diagram bukan reproduksi model baku; pembatasan cakupannya dijelaskan pada masing-masing unit.

## Pemeriksaan editorial

Setiap gambar ditinjau untuk kesesuaian adegan, hubungan dengan latihan, martabat anak, dan keterbacaan. Detail naratif pada teks kasus tetap menjadi dasar analisis; ekspresi dalam gambar tidak digunakan untuk diagnosis. WebP mempertahankan komposisi gambar dengan kompresi untuk web. Seluruh aset dimuat melalui jalur relatif; tidak bergantung pada layanan gambar eksternal.
